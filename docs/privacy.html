Privacy Policy

Effective date: November 4, 2026

This Privacy Policy explains how the independent project “Shorts Automation” accesses and handles information when its owner runs its automated video workflows.

Who uses this application

The application is operated by its project owner for the owner's YouTube channels. It does not provide public user registration or offer account management to third parties.

Google and YouTube data accessed

When the owner enables YouTube publishing, the application uses Google OAuth authorization and the YouTube Data API upload permission to upload videos, titles, descriptions, tags and publication settings to the owner's authorized channel.

When optional analytics collection is configured and separately authorized, the application uses the YouTube Analytics read-only permission to retrieve channel video report metrics. The configured report can include views, engaged views, average view duration, average view percentage, likes, comments, shares and subscribers gained for videos over a selected reporting period.

The application does not use Google user data for advertising, sell it, or use it to build profiles of people. It does not request access to Gmail, contacts, calendars, or Google Drive.

How information is used

  • OAuth credentials are used to obtain authorized access tokens from Google and perform the owner-enabled YouTube upload or analytics operation.
  • Video files and related publishing metadata are used to publish the owner's generated videos.
  • Analytics metrics are used only to review the performance of the owner's videos and inform content planning.

Storage and retention

OAuth client credentials and refresh tokens are configured as encrypted GitHub Actions repository secrets. They are supplied to workflow processes at runtime and are not intentionally written to workflow logs or generated reports.

Generated video files may be stored as GitHub Actions artifacts for the configured artifact-retention period (currently 3 days for daily videos). Analytics snapshots may be stored in GitHub Actions artifacts for up to 90 days and in the workflow's GitHub Actions cache for reuse by later runs, subject to GitHub's cache retention and eviction rules.

Google handles OAuth authorization and YouTube API requests under Google's own terms and privacy practices. GitHub hosts the source code and runs the automated workflows under GitHub's terms and privacy practices.

Sharing

The application does not sell or rent Google user data and does not share it with data brokers. Data is transmitted only to Google services needed for the authorized YouTube operation and to GitHub services used to run workflows and retain configured artifacts or cache data. Videos that the owner chooses to publish with public visibility become publicly available on YouTube.

Security and revoking access

Access is limited to the OAuth scopes configured for the enabled features. The owner can revoke the application's Google access through the Google Account third-party connections page and can remove or replace repository secrets in GitHub. Revoking authorization prevents future API operations until access is granted again.

Children

This project is an automation tool for its owner and is not designed for children or directed to children.

Changes and contact

This policy may be updated when the application's features or data practices change. The current version will be published on this page.
