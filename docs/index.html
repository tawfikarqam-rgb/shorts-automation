Independent automation project

Shorts Automation

Tools and workflows for creating short-form videos and publishing them to YouTube channels controlled by the project owner.

What the application does

Shorts Automation runs scheduled or manually started workflows that select a story topic, prepare a short video script, assemble a vertical video using sourced visual assets, narration and subtitles, and save the resulting video as a workflow artifact.

When the owner enables YouTube publishing and grants permission, the workflow uploads the generated video to the owner's selected YouTube channel. The workflow can also read channel-level video analytics to help review performance. Analytics collection is optional and does not determine whether video generation succeeds.

Google and YouTube access

The application requests YouTube permissions only for the functions enabled by the owner: uploading videos and, when configured, reading YouTube Analytics reports. OAuth credentials are used by automated workflows and are stored as encrypted repository secrets in GitHub Actions. The application is intended for the project owner's own channels, not for public sign-up or third-party account management.
